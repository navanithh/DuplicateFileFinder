Duplicate File Finder

Project Overview

Duplicate File Finder is a Java-based desktop application that helps users identify and manage duplicate files in a selected folder.

Technologies Used

- Java
- Java Swing (GUI)
- SHA-256 Hashing
- Multithreading

Features

- Select a folder using a folder picker.
- Find duplicate files based on file size and SHA-256 hashing.
- Filter files by minimum size and extension.
- Display duplicate files in a results table.
- Show scanning progress with a progress bar.
- Cancel the scanning process.
- Automatically select duplicate files.
- Move duplicate files to a separate trash folder.
- Export duplicate file results to CSV.

How to Run

Compile:

javac DuplicateFileFinderGUI.java

Run:

java DuplicateFileFinderGUI

Project Objective

The main objective of this project is to identify duplicate files, reduce unnecessary storage usage, and help users manage their files efficiently.
